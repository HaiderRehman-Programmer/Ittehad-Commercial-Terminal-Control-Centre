# 🏢 Ittehad Commercial Terminal Control Centre — Web Release (`gh-pages`)

> **Live Deployment:** [https://haiderrehman-programmer.github.io/Ittehad-Commercial-Terminal-Control-Centre/](https://haiderrehman-programmer.github.io/Ittehad-Commercial-Terminal-Control-Centre/)

This branch (`gh-pages`) contains the compiled production distribution assets for the **Ittehad Commercial Terminal Control Centre** enterprise real estate management application.

---

## ⚡ Overview & Features

- 📊 **Real-time Dashboard Metrics:** Overview of sales, collections, pending approvals, and property availability.
- 🏢 **Property & Plot Management:** Interactive plot booking, status tracking, and dossier management.
- 💳 **Installments & Financial Ledgers:** Customer ledgers, payment tracking, balance sheets, and trial balances.
- 🗺️ **Interactive Site Maps:** Visual mapping and terminal control interface.
- 🔒 **Role-Based Access Control:** Configurable user permissions and audit trail logging.

---

## 🛠️ Build & Tech Stack

- **UI Framework:** React 19 & React DOM 19
- **Bundler:** Vite 8
- **Styling:** Tailwind CSS v4
- **Router:** HashRouter (optimized for static page hosting)
- **Deployment Engine:** GitHub Pages (`gh-pages`)
